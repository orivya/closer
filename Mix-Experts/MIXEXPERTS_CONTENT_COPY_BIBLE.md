# 1. BRAND VOICE GUIDELINES

## 1.1 Voice Characteristics

| Trait | Description | Example |
|-------|-------------|---------|
| **Confident** | We know audio professionals | "The platform built for engineers" not "A platform that might help" |
| **Warm** | Supportive, not corporate | "We've got your back" not "We provide solutions" |
| **Direct** | Clear, no fluff | "Start free" not "Begin your journey today" |
| **Expert** | Industry-aware | Use correct terminology (stems, DAW, bus compression) |
| **Encouraging** | Celebrate wins | "Your profile is looking great!" |

## 1.2 Tone by Context

| Context | Tone | Example |
|---------|------|---------|
| Marketing | Aspirational, confident | "Your sound. Your brand. Your business." |
| Onboarding | Friendly, guiding | "Let's set up your profile — it only takes a few minutes." |
| Dashboard | Professional, efficient | "3 new inquiries this week" |
| Errors | Helpful, not blaming | "We couldn't save that. Try again?" |
| Success | Celebratory, brief | "Done! Your profile is live." |

## 1.3 Words We Use vs. Avoid

| Instead of... | We say... |
|---------------|-----------|
| Users | Engineers, professionals, you |
| Platform | MixExperts |
| Purchase | Get, upgrade, unlock |
| Utilize | Use |
| Leverage | Use |
| Terminate | Cancel |
| Invalid | Not quite right |
