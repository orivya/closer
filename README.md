# Closer — Premium Dashboard Mock

This repo contains a single-file HTML prototype plus a Next.js app scaffold.

## Preview

- Open `index.html` directly in your browser (redirects to the latest prototype), **or**
- Run a tiny local server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

Current canonical prototype: `closer_world_class_premium_dashboard_refined_2026_clean.html`

## Next.js App (Recommended)

```bash
cd closer-web
npm install
npm run dev
```

Then open `http://localhost:3000`.

Dev-only route list: `http://localhost:3000/dev/route-index`
